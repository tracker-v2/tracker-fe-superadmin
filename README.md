This super admin for managing and monitoring the Matador Tracker system. It provides a centralized dashboard for administrators to oversee data, optimize workflows, and ensure reliable performance across the platform.

## Technology

- Tailwind
- Radix-UI
- Lucide React
- Zustand
- React Router Dom
- Clsx

## Getting Started

Follow these steps to get started with the react-vite-ui template:

```bash
# Clone this repository
git clone

# Navigate to the project repository
cd tracker-superadmin-fe

# Install the dependencies:
npm install

# Start the development server:
npm run dev

```

## Shorcut Scripts

- `npm run dev` Start the development server
- `npm fix audit` a
- `npm build` Builds the production-ready code.
